Para atender

    Respaldo

    En el celular, «Guardar respaldo» te deja mandarlo a Google Drive, WhatsApp o donde quieras. Con eso Claude Code lo puede leer desde tu computadora.

    Traer notas de ColorNote

    Tus notas se siguen escribiendo y guardando en ColorNote; acá se trae una copia para poder hacerle preguntas. En ColorNote: Configuración → Respaldo → Respaldar. Después elegí ese archivo acá. Si nunca le pusiste contraseña a ColorNote, dejá 0000.
